Fonts embedded in AWS User Group Madurai badge artifacts
========================================================

Two font families are subsetted and embedded (as base64 woff2) into every badge
SVG produced by tools/badge-renderer. Both are licensed under the SIL Open Font
License, Version 1.1, which explicitly permits embedding. See condition 5 and
the PREAMBLE: the requirement for fonts to remain under this license does not
apply to documents created using the fonts.

  Inter
    Copyright (c) 2016 The Inter Project Authors (https://github.com/rsms/inter)
    with Reserved Font Name "Inter".
    Used for: Latin text at weights 300, 500, 700.

  Noto Sans Tamil
    Copyright (c) 2022 The Noto Project Authors
    (https://github.com/notofonts/tamil)
    with Reserved Font Name "Noto".
    Used for: Tamil text (U+0B80-0BFF) at weights 500, 700.

Note on the Reserved Font Names: the badge renderer declares the embedded faces
under the local CSS family alias "AWSUGMDU Sans". This is an alias for the
@font-face declaration only, applied to unmodified subsets of the original
fonts. No glyph outlines are altered. Subsetting removes unused glyphs and does
not constitute a Modified Version under this license, so the Reserved Font Name
restriction in condition 3 is not engaged. The original names are recorded in
tools/badge-renderer/fonts.generated.json.
